# 00 - 前置知识：先认识模型、数据和评测

本章面向会一点 Python、但还不太懂大模型的同学。如果已经能完成下面的自测，可以直接进入 [01 DCAI 基础](../01-dcai-foundations/)。

## 开始前需要会什么

- 会运行一个 Python 脚本，认识列表、字典和函数。
- 能读取、修改一条 JSON 数据；还不会的话，可以先打开首个实验的 `data.json`，对照脚本里的 `json.load` 学习。
- 暂时不要求掌握 Transformer 推导、强化学习或分布式训练。

## 默认教材：复旦 NLP《大规模语言模型：从理论到实践》

[官网](https://intro-llm.github.io/)提供完整电子版、课件和[配套代码](https://github.com/intro-llm/intro-llm-code)。本指南把它作为 LLM 前置知识的主线，先建立概念，再按需回查。初次学习不用通读全书，也不用先跑完书中的训练项目。

不同版本的章节编号可能不同，下面按主题列出阅读范围：

| 顺序 | 找到这些主题 | 第一遍读到什么程度 | 本指南中的用途 |
| --- | --- | --- | --- |
| 1 | 绪论、大语言模型基础 | 知道 token、语言模型和下一 token 预测是什么；认识 Transformer 的用途，暂时跳过公式推导 | 看懂模型输入与输出 |
| 2 | 预训练数据 | 知道数据来源、清洗、去重与训练目标的关系 | 进入 05 数据处理 |
| 3 | 有监督微调／指令微调 | 能辨认指令和回答，区分预训练与 SFT；知道 LoRA 用来减少微调时需要训练的参数 | 看懂 03 的生成样本和 08 的训练数据 |
| 4 | 大语言模型评估 | 分清验证集与测试集，理解正确率、答案提取和评测条件 | 公平地比较改数据前后的结果 |

读的时候可以同时参考[术语与样本说明](./llm-basics.md)。对初学者来说，能解释一个例子比背下所有名词更重要。

分布式训练、强化学习／RLHF、多模态和效率优化留到相关实践时再读。如果只想先做 RAG，可以在基础概念之后选读书中的检索增强生成部分，再进入 [10](../10-rag-and-extraction/)。

## 第一次动手

运行[数据纠错与去重实验](./first-dcai-experiment/)：无需 GPU、API Key 或下载模型，只使用 Python 标准库。

它用一个简单文本分类器，帮助你观察同一个模型在不同训练数据上会怎样变化。这个实验不训练大语言模型；它先让你熟悉 DCAI 实验中的对照、数据划分和错误分析。

## 本章完成标准

不查资料，试着回答：

1. 让模型回答问题，和用问答数据微调模型，有什么区别？
2. 一条指令微调样本中的输入和目标输出分别是什么？
3. RAG 在回答前找到了新资料，是否就意味着模型参数更新了？
4. 为什么不能看到测试集答案后，再据此修改训练集标签？
5. 去重后分数没涨，是否就说明去重没有价值？你还会检查什么？

参考解释见[术语说明](./llm-basics.md)与[实验说明](./first-dcai-experiment/)。能说明这些问题并读懂实验结果，就可以继续学习；不必等待“所有基础都学完”。

## 遇到基础问题时再查这些资料

### ML/DL 基础

- [李宏毅机器学习](https://speech.ee.ntu.edu.tw/~hylee/ml/2023-spring.php)：按需补训练、过拟合、梯度下降和 Transformer。
- [动手学深度学习](https://d2l.ai/)：需要代码例子时，查阅数据处理、模型训练和文本相关章节。

### LLM 课程与研究阅读

- [Stanford CS324](https://stanford-cs324.github.io/winter2022/)：建立基础后进一步学习语言模型。
- [Stanford CS25](https://web.stanford.edu/class/cs25/)：按兴趣选择报告，不作为第一阶段必修。
- [人民大学 LLM 综述](https://arxiv.org/abs/2303.18223)：用于查找主题和参考文献。
- [Attention Is All You Need](https://arxiv.org/abs/1706.03762)、[BERT](https://arxiv.org/abs/1810.04805)、[ResNet](https://arxiv.org/abs/1512.03385)：深入对应模型时再读。

### 进入 RL/RLHF 方向后

- [Sutton & Barto 强化学习教材](http://incompleteideas.net/book/the-book-2nd.html)
- [复旦教材的强化学习部分](https://intro-llm.github.io/)
- [RLHF 综述](https://arxiv.org/abs/2404.18922)
