# 第一个 DCAI 实验：只改训练数据，会发生什么？

你将训练一个短评分类器，判断一句英文短评是正面（positive）还是负面（negative），然后只修改训练数据，再比较预测。使用英文短句是为了用最简单的单词切分解释实验，说明和代码注释均为中文。

这是人工构造的小型教学数据和朴素贝叶斯模型，不是 LLM 微调实验。它帮助你认识数据质量、重复样本、独立评测和对照实验；分数不代表真实任务效果。

## 运行条件与命令

- Python 3.9 或更新版本，Windows、macOS、Linux 均可使用相应的 Python 解释器运行。
- 只使用标准库，无需安装第三方包、下载模型、配置 API Key 或使用 GPU。

先将本仓库下载或克隆到电脑，在仓库根目录打开终端：

```bash
python3 --version
python3 00-prerequisites/first-dcai-experiment/run_demo.py
```

如果系统使用 `python` 命令，就把命令中的 `python3` 换成 `python`；Windows 也可使用 `py -3`。如果提示找不到脚本，检查当前目录中是否有本仓库的 `README.md` 和 `00-prerequisites` 文件夹。

需要保存逐条结果时：

```bash
python3 00-prerequisites/first-dcai-experiment/run_demo.py --output output/first-dcai-result.json
```

## 先看数据，再看分数

打开 [data.json](./data.json)。它包含：

| 字段 | 内容与用途 |
| --- | --- |
| `train` | 20 条训练短评，其中包含重复且标错的样本 |
| `label_corrections` | 人工核查训练短评后记录的纠错表，只引用训练样本 ID |
| `validation` | 4 条验证短评；本实验没有调参，只展示这一划分的用途 |
| `test` | 8 条测试短评；各组使用相同测试集，标签只用于评分 |

例如，`bad stale meal` 描述负面体验，但 `d01` 到 `d08` 都将它标成 positive。这些样本与原有负面训练样本重复。纠错表依据训练短评的含义编写，没有使用测试答案。

运行时依次比较三组：

1. **raw**：原始训练数据。
2. **corrected**：只修正纠错表中的标签，样本条数不变。
3. **corrected_deduplicated**：在第二组基础上去重，保留每种文本一条。

每组都从头训练同一种模型，模型方法、平滑参数和评测规则固定。变化的是训练数据以及由此学到的词频和类别分布。去重后训练条数减少，所以不能把这一组解释成“等训练开销”实验。

## 默认数据的参考结果

| 组别 | 训练条数 | 验证正确数 | 测试正确数 |
| --- | ---: | ---: | ---: |
| raw | 20 | 3/4 | 6/8 |
| corrected | 20 | 4/4 | 8/8 |
| corrected_deduplicated | 12 | 4/4 | 8/8 |

终端还会显示每条测试短评在三组中的预测。默认数据中，`t05`、`t06` 从误判正面变成了负面。

这个例子说明错误标签可以影响其他短评的预测，重复也会改变训练词频。本次去重后正确率没变，但训练数据从 20 条减至 12 条。这里没有测量耗时，不据此声称获得了某个加速比例。8 条测试数据非常少，也不能据此推断真实任务中必然提高 25 个百分点。

## 试着解释，再做修改

1. **解释结果**：为什么纠错不改变训练条数，却改变了预测？为什么去重后分数可能不变？
2. **看训练数据**：从 `run_demo.py` 的 `fit` 开始读，找到模型如何按类别统计单词。先理解输入和输出，再考虑公式。
3. **设计下一次实验**：如果要比较“12 条去重数据”和“12 条随机抽样数据”，应如何控制抽样种子、类别分布和评测条件？

不要为了让参考分数更高而反复照着这 8 条测试答案改数据。继续设计清洗规则时使用训练集与验证集，并为最终检验保留新的独立测试数据。训练、验证、测试之间不能出现完全相同的文本；真实数据还需要进一步检查近重复、同源文档和时间泄漏。

## 如何确认实验的数据边界

脚本会检查跨划分的重复文本、纠错表是否引用测试集，以及去重前是否存在标签冲突。它不能自动发现所有语义近重复。

运行这些检查的回归测试：

```bash
python3 -m unittest discover -s 00-prerequisites/first-dcai-experiment -p 'test_*.py' -v
```

测试还会反转测试标签，检查模型预测是否保持不变：测试标签应该影响评分，不能影响训练与预测。检查项不要求清洗后的分数总是上涨。
